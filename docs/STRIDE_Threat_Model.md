| Phân Loại (STRIDE) | Thành Phần Bị Ảnh Hưởng | Kịch Bản Tấn Công / Rủi Ro | Giải Pháp Giảm Thiểu (AWS Mitigations) |
| :--- | :--- | :--- | :--- |
| **Spoofing** (Giả mạo danh tính) | ALB (Public Entry), EC2 Web App | Kẻ tấn công giả mạo IP, Client hoặc request HTTP hợp lệ để truy cập trái phép. | **AWS WAF**: Lọc header giả mạo, kiểm tra IP Reputation List. <br> **NACL & Security Group**: Chỉ nhận traffic hợp lệ qua ALB; EC2 chỉ nhận từ ALB. |
| **Tampering** (Can thiệp / Sửa đổi) | Dữ liệu truyền tải (In-transit), Dữ liệu lưu trữ (EBS, RDS, S3) | MitM nghe lén/sửa đổi gói tin HTTP; Mã độc sửa đổi dữ liệu DB hoặc log S3. | **HTTPS/TLS**: Mã hóa đường truyền. <br> **AWS KMS**: Mã hóa EBS, RDS, S3. <br> **S3 Versioning / Object Lock**: Chống xóa/sửa log. |
| **Repudiation** (Chối bỏ trách nhiệm) | Toàn bộ hệ thống (ALB, EC2, Database) | Kẻ tấn công/nội bộ phá hoại nhưng không để lại log để điều tra, quy trách nhiệm. | **Amazon GuardDuty**: Giám sát VPC Flow & DNS logs. <br> **ALB Access Logs**: Lưu toàn bộ log về S3. <br> **CloudWatch Logs**: Ghi nhận hoạt động ứng dụng. |
| **Information Disclosure** (Lộ lọt thông tin) | EC2 Web Server, Mã nguồn & Config, Database RDS | Lộ credentials DB; SQL Injection; Database bị quét cổng trực tiếp từ Internet. | **AWS Secrets Manager**: Quản lý credentials tập trung. <br> **AWS WAF**: Bật SQLi RuleSet. <br> **Private Subnets**: Đặt EC2/RDS trong mạng Private, ngắt Public IP. |
| **Denial of Service** (Từ chối dịch vụ) | ALB, EC2 Compute Instances | HTTP Flood làm cạn kiệt tài nguyên CPU/RAM EC2 hoặc làm nghẽn băng thông mạng. | **AWS WAF Rate-based Rule**: Chặn IP vượt ngưỡng (>100 req/5p). <br> **AWS Shield Standard**: Chống DDoS L3/L4. <br> **ALB Multi-AZ**: Cân bằng tải qua nhiều AZ. |
| **Elevation of Privilege** (Leo thang đặc quyền) | Máy chủ EC2, Quyền IAM trên AWS | Chiếm shell EC2, nâng quyền Root hoặc lấy cắp AWS Token để thao túng cloud. | **IAM Role**: Áp dụng Least Privilege. <br> **Security Group EC2**: Chặn SSH port 22, dùng AWS SSM. <br> **Security Group RDS**: Chỉ nhận inbound từ EC2 SG. |
